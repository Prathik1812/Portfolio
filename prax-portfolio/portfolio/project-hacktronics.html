Hacktronics 2.0

A full event identity for the Department of ECE's flagship tech fest — one wordmark carried across posters, a landscape banner, and 60+ individual organizer ID cards.

ClientDept. of ECE, AU
DomainEvent Branding
RoleGraphic Designer
Year2026

The System

Hacktronics 2.0 runs across four technical tracks — Robotics, AIIoT, Tracksat and VLSI — so the wordmark was built as a stacked, circuit-textured monogram that reads at poster scale and compresses cleanly into a single badge for credentials and social tiles.

The same navy-and-white system carries from the portrait event poster to a landscape banner for digital placements, and down to a badge-style ID card issued to every organizer.

Organizer ID System

A single dark template — name set in large serif type, role label, university crest — was produced for every organizer on the team, so the fest's ~60-person crew all carried one consistent credential rather than ad-hoc name tags.

Outcome

One identity, scaled from
poster wall to lanyard.
